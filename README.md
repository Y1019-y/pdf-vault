# 我的 PDF 收纳网页

一个纯本地、零依赖的个人 PDF 收纳网页：把 PDF 拖进网页即自动保存，之后打开网页即可直接查看和管理。数据不上传任何服务器。

## 使用方法

**在线版（推荐）：https://y1019-y.github.io/pdf-vault/** —— 任何电脑用 Edge/Chrome 打开此链接即可使用，无需安装或拷贝文件。

本地版：用 **Edge 或 Chrome** 双击打开 `index.html` 即可使用（无需安装、无需联网）。

1. 把 PDF 文件拖进网页 → 自动保存。
2. 点击卡片 → 全屏查看 PDF（Esc 或「关闭」退出）。
3. 在资源管理器 / 微信等地方复制了 PDF 文件后，回到网页按 **Ctrl+V** 即可粘贴保存。
4. 双击卡片（或菜单里选「重命名」）可以改名。

## 功能一览

| 功能 | 操作方式 |
|---|---|
| 拖拽保存 | 把 PDF（可多个）拖进网页任意位置 |
| 粘贴保存 | 复制 PDF 文件后按 Ctrl+V |
| 点击查看 | 单击卡片，全屏渲染 |
| 置顶 | 卡片左下角 ☆ 图标，置顶卡片排最前 |
| 复制 | 卡片 ⋯ 菜单 → 复制（生成副本） |
| 重命名 | 双击卡片 或 ⋯ 菜单 → 重命名 |
| 搜索 | 顶部搜索框，按文件名实时过滤 |
| 下载 | ⋯ 菜单 → 下载（另存为原文件） |
| 删除 | ⋯ 菜单 → 删除（有确认提示） |
| 导出备份 | 顶栏「导出备份」，全部 PDF 打包成一个 .json 文件 |
| 导入备份 | 顶栏「导入备份」，选择 .json 文件恢复数据 |

## 重要注意事项

- **数据保存在当前浏览器的 IndexedDB 中**，不会写入磁盘文件，也没有任何联网上传。
- ⚠️ 在线版与本地版是**两套独立的数据**（浏览器按网站地址分开存储），互不可见；两者之间用「导出备份 / 导入备份」迁移。
- 换电脑、换浏览器、或移动本文件夹位置后，旧数据可能看不到 →
  请先在原环境点「导出备份」，再到新环境「导入备份」。
- 支持 Edge / Chrome，以及 360 浏览器的「极速模式」（Chromium 内核）。
  360安全浏览器若用 IE 兼容内核打开会无法使用，请点击地址栏图标切换到极速模式；推荐直接使用在线版链接。
  Firefox 在 file:// 下对剪贴板等支持较差。
- 删除后无法恢复，请谨慎操作。
- 隐私（无痕）模式下浏览器存储不可用，请用普通窗口打开。
